## Замечания
1. **[major, исправлено ревьюером]** `custom/app/services/custom/push.rb#deliver`: ловились только «подписка
   протухла». Таймаут, 429 или 5xx push-сервиса у одного устройства бросали исключение из цикла. Получатели после
   него уведомления не получали, задача уходила в повтор Sidekiq, и первые получали его ещё раз. Повторы упирались
   в то же устройство. У upstream (`Notification::PushNotificationService#handle_browser_push_error`) ошибки
   обрабатываются по каждому устройству. Исправление: прочие ошибки устройства пишутся в лог, рассылка идёт
   дальше. Спек «still notifies the others when one device fails», без исправления падает (проверено).
2. **[minor]** `manifest.webmanifest` отдаётся как `text/plain`. Android это принял. Для порядка можно зарегистрировать
   `application/manifest+json` в `Mime::Type` (из `custom/config/initializers`). → этап L.1.
3. **[minor]** Ничейный чат уведомляет всех не-фрилансеров аккаунта, без проверки, что человек состоит в inbox'е
   номера. Сейчас менеджеры во всех inbox'ах, так что верно. Если появится менеджер «не на всех номерах», это надо
   пересмотреть. Действий не требует.
4. **[blocker по правилам репозитория, исправлено]** В `crm/PROGRESS.md` (D3c, D4) и `crm/reviews/stage-D.md` были
   логин и имя реального фрилансера. По решению человека заменены на `test_freelancer` / «Test Freelancer» в файлах и
   в истории: локальная история с коммита D3c переписана (`git filter-branch --tree-filter`), проверено `git log -p` —
   0 вхождений. Итоговое дерево отличается только этими строками. Ветку надо пушить с `--force-with-lease` (человек).
