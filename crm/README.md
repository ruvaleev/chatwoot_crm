# crm/ — рабочее место для доработок форка

Форк Chatwoot под наш процесс: WhatsApp-номера фрилансеров (через Evolution API, без WhatsApp Business),
бесшовная передача клиента фрилансеру, уведомления и эскалации в Telegram, скрытие номера клиента, позже
ИИ-ответы ночью. Деплой — Kamal на один VPS.

## Где что

| Путь | Что |
|---|---|
| `crm/AGENTS.md` | контекст и правила для агентов (дополняют и частично переопределяют корневой `AGENTS.md`) |
| `crm/PRD.md` | этапы, задачи, критерии приёмки |
| `crm/REVIEW.md` | инструкция ревьюера |
| `crm/HUMAN.md` | твои задачи и блокеры по порядку |
| `crm/PROGRESS.md` | журнал исполнителя (создаётся на этапе 0) |
| `crm/reviews/` | вердикты ревьюера по этапам |
| `crm/docs/` | runbook, гайды для менеджеров и фрилансеров, реестр правок upstream `core-changes.md` |
| `custom/`, `spec/custom/` | наш код и спеки (штатный механизм расширений Chatwoot) |
| `config/deploy.yml`, `.kamal/`, `script/crm/`, `.github/workflows/crm-*.yml` | деплой, скрипты сервера, CI |

## Цикл работы

1. Пройди `crm/HUMAN.md`, начиная с **H0**: запушить `main` от релиза, отключить upstream CI.
2. Исполнитель (отдельная сессия `claude` в корне репозитория):
   «Ты исполнитель. Выполни следующий незакрытый этап из crm/PRD.md».
3. Ревьюер (другая сессия):
   «Ты ревьюер. Проверь этап со статусом ready for review по crm/REVIEW.md».
4. `CHANGES REQUESTED` → исполнитель отвечает на замечания в `crm/reviews/stage-N.md` → повторное ревью.
   `PASS` → следующий этап.
