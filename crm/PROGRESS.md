## 2026-11-07 · Этап 6 · in progress (часть 2: номер клиента)

**Сделано**
- `Custom::PhoneScrubber` — очистка JSON для фрилансера по ключам, поэтому работает везде, куда встроен контакт
  (карточка, `meta.sender` диалогов, `sender` сообщений, уведомления, поиск): `phone_number` → `null`;
  `identifier` и `source_id` с 6+ цифрами подряд → `null` (у Evolution `identifier` = `<номер>@s.whatsapp.net`);
  `name`, состоящее из номера (WhatsApp-контакт без имени), → «Клиент •••NN» (I18n `crm.contact.masked_name`,
  ru/en, `custom/config/locales`). Текст сообщений не трогается: если клиент сам написал номер, его видно.
- HTTP: `after_action` на `Api::V1::Accounts::BaseController` (новая точка расширения, правка upstream в
  реестре) — все JSON-ответы `/api/v1/accounts/*` фрилансеру проходят через очистку.
- Real-time: `broadcast` отправляет фрилансерам отдельную, очищенную копию события, остальным — как в upstream.
- Поиск по телефону для фрилансера пустой: запрос с 6+ цифрами в `/search` (диалоги и контакты) и
  `/contacts/search`, фильтр контактов по `phone_number` / `identifier`. Поиск сообщений по тексту работает.
- Форма контакта фрилансера не затирает данные: `phone_number` и `identifier` из обновления выбрасываются, маска в
  `name` не сохраняется.
- Спеки: `spec/custom/services/custom/phone_scrubber_spec.rb`, раздел «client phone number» в
  `freelancer_isolation_spec.rb`, копия события в `action_cable_listener_spec.rb`. `script/crm/test`: 245 примеров,
  0 падений; дополнительно upstream-спеки контроллеров диалогов, сообщений, назначений — 135, 0 падений.

**Решения**
- Очистка на выходе, а не правка jbuilder'ов и `push_event_data`: одна точка для всех ответов и событий, без
  копий upstream-кода. Маскировка в модели (`Contact#phone_number`) отвергнута: real-time payload собирается в
  запросе того, кто действовал, и уходит всем — маска попала бы и менеджерам, а серверной логике номер нужен.

**Известные ограничения / для ревьюера**
- Ключ `phone_number` обнуляется у любых объектов в ответе фрилансеру, в т. ч. его собственный телефон в профиле
  агента и номер WhatsApp-inbox'а (это его же номер). На работу не влияет.
- Сортировка контактов по `phone_number` фрилансеру доступна (порядок без значений, утечка пренебрежима).
- Фронтенд с пустым номером: форма и кнопка звонка рассчитаны на контакты без телефона (как у веб-виджета);
  в живом UI под фрилансером проверить человеку.
- Медиа и вложения: имена файлов от Evolution — id сообщений, номеров в них не замечено.

**Проверить человеку**
- Под фрилансером: карточка контакта, список диалогов, Contacts — номера нет, у контакта без имени — «Клиент •••NN»;
  в консоли браузера нет ошибок; поиск по цифрам номера ничего не находит; сохранение карточки (например, email)
